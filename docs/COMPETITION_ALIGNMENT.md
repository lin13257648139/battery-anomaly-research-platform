# 赛道契合度与提交边界

用户提供的荣誉证书属于 2025–2026 年度第八届“传智杯”AI 云计算大数据开发挑战赛 B 组省赛。该届提交页面已关闭，现有公开页面无法核实其完整评分表、文件大小、视频时长和材料格式。**不能据此保证当前项目符合往届或下一届的全部正式提交规则。**提交前须以当届官网与学校通知为准。

公开的[第八届校级通知](https://jwch.xsyu.edu.cn/info/1094/3804.htm)确认了该赛道及研究生、大学 A/B、高职 C 组；[第九届校级通知](https://cs.dgut.edu.cn/info/1034/19118.htm)显示下一届仍有 AI 云计算大数据开发方向，但赛事形式和材料要求可能变化。

| 赛道要素 | 当前项目的实际证据 | 尚不能宣称 |
|---|---|---|
| AI | PyTorch 时序卷积自编码器、Isolation Forest 与物理基线在固定车辆测试组比较；保留失败结果和置信区间 | 深度模型优于基线、真实提前预警 |
| 大数据开发 | Spark 3.5.9 处理 2,486 万采样行；与独立 pandas 逐键逐列一致；Spark Structured Streaming 历史回放去重与恢复 | 多机器集群吞吐、真实车辆在线流 |
| 云计算 | Docker 化 API/看板与可迁移的 OSS、EMR、容器服务设计 | 云端实际部署、云费用与 SLA |
| 工程交付 | 来源哈希、安全转换、数据质量、实验报告、运行脚本、看板、PPT 和讲稿 | 真实商业产品或安全认证 |
